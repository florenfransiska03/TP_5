Apa itu bootstrap dan apa kegunaannya?
Bootstrap adalah framework CSS yang digunakan untuk mempermudah dan mempercepat pembuatan tampilan website menggunakan HTML, CSS dan JavaScript. Bootstrap menyediakan komponen dan desain siap pakai sehingga kita ga perlu membuatnya dari awal. Kegunaan nya ada membuat website responsif, mempercepat pembuatan tampilan, membuat desain lebih konsisten, mempermudah  pengaturan layout.

Memasang bootstrap sebutkan cara caranya?
1. Memasang dengan CDN dengan membuat proyek HTML lalu memasang link pada head dan bodynya
2. Memasang dengan mengunduh file resmi bootstrap

Jelaskan mengenai class grid dan kegunaan breakpoint?
grid adalah sistem tata letak pada bootstrap yang digunakan untuk mengatur elemen website dalam bentuk baris dan kolom.
breakpoint adalah batas ukuran layar yang digunakan bootstrap untuk menyesuaikan tampilan website pada berbagai perangkat, seperti HP, tablet, dan komputer.

Sebutkan minimal 5 class yang disediakan beserta kegunaannya
1. container: membungkus konten dan mengatur lebar area website
2. row: membuat baris untuk menyusun kolom pada sistem grid
3. col: membuat kolom untuk mengatur tata letak elemen
4. text-center: untuk membuat teks rata tengah
5. btn btn-primary: membuat tombol dengan warna biru

Bagaimana cara agar foto atau gambar pada website reponsif menyesuaikan ukuran layar perangkat?
menggunakan img-fluid membuat gambar memiliki lebar maksimal 100% dari kontainernya dan tinggi otomatis mengikuti proporsi gambar, sehingga gambar tidak melampaui ukuran kontainer dan tidak terdistorsi.
